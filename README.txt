# 02 House Price

## Run in VS Code
1. Open this folder in VS Code.
2. Open Terminal → New Terminal.
3. Install libraries: `python -m pip install pandas scikit-learn`
4. Run: `python house_price.py`

The folder includes a small **synthetic demo dataset** named `houses.csv` with the columns expected by the program. It is for learning and testing the code, not real-world prediction.

Note: predictions from synthetic demo data are only demonstrations. Replace the CSV with a suitable, reliable dataset for meaningful results.
